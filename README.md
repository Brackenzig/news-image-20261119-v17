A newspaper front page summing up 19 November 2026's world news in one image — 43 verified stories from every continent, all from this one day. Built on the winning pattern: hard-news leads (Shenzhen trilateral summit, ICJ Myanmar genocide ruling, COP31), a 7-region count strip, a date-check box, a timeline strip, and a light world map with numbered pins. The image is drawn from scratch with PIL by `build_v17.py`; `main.ts` copies it to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
